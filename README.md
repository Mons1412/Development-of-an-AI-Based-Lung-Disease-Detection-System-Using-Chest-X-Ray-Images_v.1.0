# LungXrayAI 2.0

**Development of an AI-Based Lung Disease Detection System Using Chest X-Ray Images**

LungXrayAI 2.0 is a Web-based application that uses Deep Learning to assist with chest X-ray image classification.

The system uses a MobileNetV2-based classifier to classify chest X-ray images into three classes:

- Normal
- Pneumonia
- Tuberculosis

In addition to AI inference, the project provides user authentication, patient profile management, medical history management, analysis history, administrative tools, PDF report generation, bilingual user interface support, and optional AI-generated explanatory content through Dr.AI.

This repository is an academic Software Engineering and Artificial Intelligence project developed for chest X-ray classification research and demonstration.

---

## Important Medical Notice

LungXrayAI is a research and educational system.

It is **not a medical diagnostic device** and must not be used as the sole basis for diagnosis, treatment, medication, or other clinical decisions.

The probabilities displayed by the application are model classification outputs. They are not the actual clinical probabilities that a patient has a disease.

Dr.AI does not independently inspect or diagnose the original chest X-ray image. It receives structured information generated by the LungXrayAI system, including classifier output and selected patient context.

Final medical decisions must be made by qualified healthcare professionals.

# Overview

The purpose of LungXrayAI 2.0 is to provide a complete experimental workflow for chest X-ray classification.

The application combines:

1. Chest X-ray image input
2. Image validation and preprocessing
3. MobileNetV2 inference
4. Prediction probability visualization
5. Patient information management
6. Medical history management
7. Analysis history storage
8. PDF report generation
9. Administrative management
10. Optional Dr.AI explanatory support

The project separates the machine learning component from the Web application and database layers.

# Key Features

## Chest X-Ray Classification

The application supports chest X-ray classification into:

```text
Normal
Pneumonia
Tuberculosis
```

The classifier returns a predicted class together with the output probability distribution for all supported classes.

---

## Single and Multiple Image Analysis

The Web interface supports analysis workflows designed for individual images as well as multiple-image processing.

The application performs input validation before the image is passed to the classifier.

---

## X-Ray Input Validation

Input validation is used to reduce invalid or unsupported files before model inference.

The system checks uploaded input before forwarding it to the classifier.

This reduces cases where unrelated images or unsupported files are incorrectly sent to the prediction pipeline.

---

## Prediction Visualization

Prediction results can be presented using multiple visualization methods, including probability-based views and charts.

This allows users to inspect both:

- the predicted class;
- the complete classifier output distribution.

---

## User Authentication

LungXrayAI 2.0 includes an authentication system that supports account creation and sign-in.

Authorization is applied to protected backend resources.

Frontend visibility rules improve the user experience, while actual authorization checks are enforced by the backend.

---

## Patient Profile

Authenticated users can maintain patient information used by the application.

Patient data is stored separately from model inference logic so that application data and machine learning components remain independently maintainable.

---

## Medical History

The system provides structured medical history management for information such as:

- existing diseases;
- smoking history;
- alcohol use;
- occupational exposure;
- allergy history.

Medical history data may be used as contextual information for Dr.AI.

It is not used by MobileNetV2 to modify the chest X-ray classification result.

---

## Analysis History

Completed analyses can be persisted and later retrieved.

Analysis history allows users to review previous results rather than relying only on the current browser session.

---

## PDF Reports

The system supports two different report purposes:

### Technical Analysis Report

Contains information related to:

- analyzed X-ray image;
- classifier result;
- probability distribution;
- model information;
- analysis metadata.

### Dr.AI Report

Contains structured explanatory information generated from the available analysis and patient context.

The Dr.AI report is separate from the classifier technical report.

---

## Administrative Functions

ADMIN users have access to administrative functionality such as:

- system overview;
- dashboard statistics;
- patient search;
- patient information review;
- analysis-related information;
- visitor statistics.

Administrative endpoints are protected by backend authorization.

---

## Bilingual Interface

The Web interface supports:

```text
English
Vietnamese
```

The selected language is stored on the client so that the interface can preserve the user's language preference.

# AI Model

## Architecture

The current deployed classifier is based on:

```text
MobileNetV2
```

Transfer Learning is used to adapt MobileNetV2 to the chest X-ray classification task.

### Model Information

| Property | Value |
|---|---|
| Classifier version | 1.1.0 |
| Architecture | MobileNetV2 |
| Input shape | 224 × 224 × 3 |
| Input channels | RGB |
| Number of classes | 3 |
| Output activation | Softmax |
| Classes | Normal, Pneumonia, Tuberculosis |
| Input normalization | [-1, 1] |
| Model format | Keras |

The runtime model package is located under:

```text
app/artifacts/lung_classifier/1.1.0/
```

The artifact bundle contains the model and supporting metadata required by the inference runtime.

Example structure:

```text
1.1.0/
├── checksums.json
├── class_indices.json
├── inference_contract.json
├── lung_classifier_v1.keras
├── metrics.json
├── model_metadata.json
├── model_runtime_requirements.txt
└── preprocessing_config.json
```

# Model Performance

The currently packaged MobileNetV2 classifier was evaluated on a balanced three-class dataset.

## Dataset Distribution

```text

```

Dataset split:

| Split | Images |
|---|---:|

| Test | 318 |

## Test Results

| Metric | Result |
|---|---:|
| Test Accuracy | 89.62% |
| Macro F1-score | 89.72% |

Class-level F1-scores:

| Class | F1-score |
|---|---:|

| Pneumonia | 0.8841 |

These values describe performance on the reported test dataset only.

They should not be interpreted as guaranteed clinical performance on real-world populations.

Dr.AI is an additional explanatory component of LungXrayAI.

```text
MobileNetV2 Prediction
        +

        |
        v
Gemini API
        |
        v
Structured Dr.AI Content
        |
        +----------------+
        |                |
        v                v
Web Interface         PDF Report
```

## Important Design Boundary

Gemini does **not** directly inspect the original X-ray pixels in the current Dr.AI workflow.

The chest X-ray image is classified by MobileNetV2.

Dr.AI then receives selected structured information produced by the application.

This design keeps image classification and language-model-generated explanation as separate responsibilities.

# Current Limitations

The current system has several important limitations.

## Classification Scope

The classifier currently supports only:

```text
Normal
Pneumonia
Tuberculosis
```

It does not provide general-purpose chest disease diagnosis.

---

## Image Classification Only

The current AI model performs image classification.

It does not perform:

```text
Object Detection
Lesion Localization
Medical Image Segmentation
```

Therefore, it does not identify the exact location of an abnormal region.

---

## Dataset Dependence

Model behavior depends on:

- training data;
- dataset quality;
- class distribution;
- image acquisition characteristics;
- preprocessing;
- differences between the development dataset and real clinical data.

Performance reported on the project test set must not be assumed to represent all hospitals, devices, populations, or clinical environments.

---

## Probability Interpretation

Softmax output values are classifier outputs.

For example:

```text
Normal:       0.10
Pneumonia:    0.82
Tuberculosis: 0.08
```

does not mean that the patient has an 82% real-world probability of pneumonia.

It means that, for the given input and model, Pneumonia received the highest relative output score among the supported classes.

---

## Dr.AI Limitations

Dr.AI may generate incorrect, incomplete, or inappropriate information.

Its output should be interpreted only as supplementary information and must not replace professional medical consultation.
