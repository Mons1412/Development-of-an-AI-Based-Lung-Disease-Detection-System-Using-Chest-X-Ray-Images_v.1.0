PROJECT OVERVIEW

AI-assisted chest X-ray classification and patient information support system.

1. Project Title and Field

Project Title: Development of an AI-Based Lung Disease Detection System Using Chest X-Ray Images

Field: Artificial Intelligence, Deep Learning, Computer Vision, and Medical Image Processing. The system uses MobileNetV2 to classify chest X-ray images into Normal Lungs, Pneumonia, and Tuberculosis.

The Web application supports image uploading, result viewing, information management, and PDF report exportation.

2. Problem Statement and Motivation

Chest X-ray imaging is commonly used to support the detection of pulmonary abnormalities. Image interpretation requires professional expertise, while patients may have difficulty understanding or remembering information exchanged during examinations.

Deep Learning can automatically learn features from medical images and support image classification. This project therefore aims to provide rapid X-ray analysis, intuitive result presentation, and information storage to support doctors and patients when referencing examination results.

The system serves solely as a support tool and does not replace medical diagnosis by a physician.

3. Project Objectives

General Objective: Build an AI-integrated Web application that assists in classifying lung X-ray images into Normal, Pneumonia, and Tuberculosis while providing a simple interface for viewing, storing, and exporting analysis results.

Specific Objectives:

  • Collect, preprocess, and organize X-ray data.
  • Train and evaluate the MobileNetV2 model.
  • Classify images into Normal, Pneumonia, and Tuberculosis.
  • Develop Backend APIs and the Web interface.
  • Display model output results and probabilities.
  • Manage user accounts, patient records, and analysis history.
  • Export analysis results as PDF reports.
  • Build a user-friendly and scalable system.

4. Scope and Limitations

Scope: The project focuses on Image Classification for chest X-ray images and is developed as a Web application for research, testing, and reference support purposes.

Limitations: The current system classifies only Normal Lungs, Pneumonia, and Tuberculosis. Object Detection for lesion localization and Medical Image Segmentation are outside the current scope.

Results depend on training data and input image quality. Displayed probabilities are model classification outputs and are not the actual probability that a patient has a disease. The system must not be used as the sole basis for diagnosis or treatment.

5. Technologies and Implementation Methods

Key Technologies: Python, TensorFlow/Keras, MobileNetV2, Google Colab, FastAPI, HTML, CSS, JavaScript, MySQL, Git, and GitHub.

AI Workflow: Data Collection -> Preprocessing -> Data Splitting -> MobileNetV2 Training -> Model Evaluation -> System Integration.

Software Development: The AI model, Backend APIs, database, and Web interface are developed in stages and then tested and integrated into the complete system.

2. Đặt vấn đề và lý do chọn đề tài

Ảnh X-quang ngực là phương pháp phổ biến trong việc hỗ trợ phát hiện các bất thường liên quan đến phổi. Tuy nhiên, quá trình đọc ảnh yêu cầu kiến thức chuyên môn, trong khi bệnh nhân có thể gặp khó khăn trong việc hiểu hoặc ghi nhớ các thông tin được trao đổi trong quá trình khám.

Sự phát triển của Deep Learning cho phép xây dựng các mô hình có khả năng tự động học đặc trưng từ hình ảnh y khoa và hỗ trợ phân loại ảnh. Vì vậy, đề tài hướng đến việc xây dựng một hệ thống giúp phân tích ảnh X-quang nhanh, trình bày kết quả trực quan và hỗ trợ lưu trữ thông tin, góp phần hỗ trợ bác sĩ và bệnh nhân trong quá trình tham khảo kết quả.

Hệ thống chỉ đóng vai trò công cụ hỗ trợ, không thay thế chẩn đoán của bác sĩ.

3. Mục tiêu của đồ án

Mục tiêu tổng quát

Xây dựng một hệ thống Web ứng dụng trí tuệ nhân tạo để hỗ trợ phân loại ảnh X-quang phổi thành ba nhóm: Normal, Pneumonia và Tuberculosis, đồng thời cung cấp giao diện đơn giản để người dùng xem, lưu trữ và xuất kết quả phân tích.

Mục tiêu cụ thể

  • Thu thập, xử lý và tổ chức dữ liệu ảnh X-quang.
  • Huấn luyện và đánh giá mô hình MobileNetV2.
  • Phân loại ảnh thành ba lớp Normal, Pneumonia và Tuberculosis.
  • Xây dựng Backend API và giao diện Web.
  • Hiển thị kết quả và xác suất đầu ra của mô hình.
  • Quản lý tài khoản, hồ sơ bệnh nhân và lịch sử phân tích.
  • Hỗ trợ xuất kết quả thành báo cáo PDF.
  • Xây dựng hệ thống dễ sử dụng và có khả năng mở rộng.

4. Phạm vi nghiên cứu và giới hạn

Đề tài tập trung vào bài toán Image Classification đối với ảnh X-quang ngực và được phát triển dưới dạng ứng dụng Web phục vụ mục đích nghiên cứu, thử nghiệm và hỗ trợ tham khảo.

Hệ thống hiện chỉ phân loại ba nhóm Phổi bình thường, Viêm phổi và Lao phổi. Đề tài chưa thực hiện các bài toán như Object Detection để xác định vị trí tổn thương hoặc Medical Image Segmentation để phân đoạn vùng bệnh.

Kết quả của hệ thống phụ thuộc vào dữ liệu huấn luyện và chất lượng ảnh đầu vào. Các giá trị xác suất hiển thị là đầu ra của mô hình phân loại, không được xem là xác suất thực tế bệnh nhân mắc bệnh. Hệ thống không thay thế bác sĩ và không được sử dụng làm căn cứ duy nhất cho chẩn đoán hoặc điều trị.
